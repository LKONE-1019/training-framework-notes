# 跨框架特性对比

本目录用于在完成各框架的独立源码分析后，对照相同特性的实现方式。目前尚未形成跨框架支持矩阵。

建议比较以下维度：

| 维度 | 需要记录的内容 |
| --- | --- |
| 分析基线 | 框架版本或 commit、分析日期 |
| 适用范围 | 模型、训练后端、硬件与并行配置 |
| 配置入口 | 参数名称、默认值与校验条件 |
| 执行流程 | 初始化、模型构建、数据加载与调度 |
| 通信与数据布局 | 通信组、张量切分、跨模块数据重分配 |
| 训练能力 | 可训练模块、反向传播、梯度同步与优化器 |
| 支持边界 | 数据形状约定、未实现分支与组合限制 |
| 验证依据 | 静态源码证据、数值验证和性能测试条件 |

未分析或未验证的项明确标注，不根据参数名称推断支持情况。
